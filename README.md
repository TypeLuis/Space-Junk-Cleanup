## Summary

This is a browser-based Asteroids-style game built using plain HTML, CSS, and JavaScript. The game runs entirely through DOM manipulation and includes ship movement, shooting, asteroid collisions, lives, and scoring.

Player data is saved using localStorage, allowing the game to remember the player’s name, highest score, total score, and customization choices between sessions. An in-game store lets players spend earned points to change the ship color and background color through a modal interface created dynamically with JavaScript.

## Controls

| Action | Key |
|------|----|
| Move | `W` / `↑` |
| Rotate Left | `A` / `←` |
| Rotate Right | `D` / `→` |
| Shoot | `Space` |
| Restart Game | `R` |
